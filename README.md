# 地震震害空间对比模拟器

> 基于地震波特征的震害简易空间对比模型 —— 三维交互模拟与遥感影像分析

一个用于**地理教学与防震减灾科普**的交互式三维模拟器。它以三类代表性建筑结构材质（钢筋混凝土、砖砌体、木结构）为核心，在同一地震烈度下直观对比它们的破坏差异，并内置一条完整的「多光谱影像 → 指数 → 分类 → 变化检测」遥感处理链，回答一个核心地理问题：

**为什么同一场地震中，不同材质的建筑破坏程度差异巨大？**

---

## ✨ 功能特性

### 房屋震害（三维交互）
- **材质决定整座城的形态**：切换钢混 / 砖砌 / 木构，整座城市会按对应结构体系重建，而非简单换色。
- **楼群按高度分三级破坏**：矮楼（≤5 层）最危险，高楼（≥24 m）主体始终直立。
- **三种倒塌形态**：钢混「坐塌」、砖砌「下沉歪倒」、木构「倾倒」，构件脱落按楼层加权。
- **破坏过程记录**：触发地震后按真实时间戳逐条追加破坏事件。
- **楼层破坏分布**：三种结构按同一烈度并排对比，每层标注完好 / 轻微 / 中等 / 严重 / 压溃。

### 人体震害（逃生姿势对比）
- 三人同框：站着不动、地震时乱跑、伏地遮挡，展示「姿势决定生死」的直观对比。

### 山体滑坡
- 按震级估算方量与滑距，分级展示小型 / 中型 / 大型 / 巨型滑坡。

### 遥感影像分析
- **多光谱栅格**：程序化生成 300×300 像元、20 m 分辨率、5 波段（B2/B3/B4/B8/B11）。
- **处理链**：真彩色合成 → 标准假彩色合成 → NDVI → 地物分类 → 变化检测。
- **悬停探针**：读取像元位置、地物类型、NDVI、光谱曲线。
- **框选统计**：以点击处为中心框选 41×41 像元，输出损毁率、NDVI 均值等统计。
- **卷帘对比**：左震前 / 右震后，随烈度实时重算。
- **制图要素**：公里网、指北针、比例尺、图例，一键导出 1800×1080 对比图。

## 🧭 地理知识内涵

- **震级 vs 烈度**：震级表征能量大小（一次地震只有一个），烈度表征破坏程度（不同地点不同），本模型采用中国地震烈度表（Ⅰ～Ⅻ 度）。
- **材质力学性质决定破坏模式**：砖砌体抗剪弱 → 脆性破坏（X 形剪切裂缝）；木结构节点薄弱 → 柔性变形 + 节点失效；钢筋混凝土延性好 → 延性破坏（塑性铰）。
- **抗震性能排序**：钢筋混凝土 > 木结构 > 砖混结构 > 砖木结构。

## 🛠 技术栈

- **Electron** — 跨平台桌面应用框架
- **Three.js** — WebGL 三维渲染（含 OrbitControls）
- **原生 HTML / CSS / JavaScript** — 前端界面与遥感影像处理算法

> 遥感影像是依据 Sentinel-2 典型地物光谱曲线**程序化生成**的多光谱栅格（非下载的真实影像），目的是让整条处理链可在单文件、离线环境下完整演示。替换为真实影像只需替换代码中的震前 / 震后波段数组。

## 🚀 快速开始

### 环境要求
- Node.js ≥ 18
- npm

### 安装与运行

```bash
# 进入应用目录
cd app

# 安装依赖
npm install

# 启动开发模式
npm start
```

### 打包为可执行文件

```bash
cd app
npm run dist
```

打包产物输出到 `dist/` 目录，生成免安装的单文件 `.exe`（Windows portable）。

> 提示：首次运行打包产物需 3~8 秒自解压，属正常现象。若出现渲染异常，可设置环境变量 `APP_DISABLE_GPU=1` 后启动，改用软件渲染。

## 📊 数据来源

模型采用的易损性矩阵与烈度数据均来自公开权威来源：

1. **国家标准**《地震灾害风险评估技术规范·房屋建筑》附录 A「不同房屋建筑结构类型易损性矩阵」。
2. **威宁县建筑物易损性矩阵**（王前锋等，地震科学进展 2026）。
3. **汶川地震砖砌体震害矩阵**（孙柏涛、张桂欣，中国力学学会 2010）。
4. **泸定 6.8 级地震房屋震害统计**（地震研究 2025）。

详细数据表格见 [`真实数据来源.md`](./真实数据来源.md)。
